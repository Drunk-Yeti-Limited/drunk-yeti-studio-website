YHETI Studio

Explore YHETI Studio, a music creation release candidate with editable MIDI parts, a synth, drum kits, audio clips, and export tools.

Your next sound starts here.

Start with a key and a groove. Build chords, bass, drums, and another instrument from musical patterns, then edit the notes and shape the sound.

Official release & downloads ↗

Find the idea

Generate, vary, or lock four MIDI parts. Work in a piano roll, explore scale types and arpeggios, and use the integrated Soloist Forge note engine for melodic or drum solos.

Shape the sound

A two-oscillator synth brings FM, morph tables, envelopes, and LFOs. An eight-pad kit combines synthesis with short sample layers, and presets keep favorite sounds close.

Build the arrangement

Arrange clips across two audio lanes, mix through six buses, and export WAV audio or notes-only MIDI. Portable project packs and recovery snapshots help preserve the work.

Choose your edition

YHETI Studio RC3 is a release candidate with defined limits, including four MIDI tracks, two audio lanes, 64 bars, and a 180-second import window per source. Optional plugin hosting has platform-specific requirements. Read the current release notes before choosing it for a production workflow.

Platforms & requirements
Windows, macOS and Linux are listed. WAV works directly; other audio formats require optional FFmpeg. Plugin hosting uses a separately installed backend.
Release notes
RC3 supports four MIDI tracks, two audio lanes, six buses and 64 bars. Linux VST3 rendering is verified in the listing; Windows/macOS plugins and hardware MIDI/audio still need qualification.
